# System design notes

Preparation notes for system design interviews, weighted toward AI/ML
infrastructure. One document per topic, added as it is written rather than
scaffolded in advance.

## Shape

The document shape comes from the first skeleton and every later document
follows it, so that revision is scanning a column rather than re-reading prose.
